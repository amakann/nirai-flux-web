配信者向け。好きなジャンル・プロンプトの曲を、自分のPCで生成。 Stable Audio 3 がローカルで動くので、クラウドの音楽APIには何も送りません。 アカウントは任意です。

できること

商用配信可

Stability AI Community License の条件内で、商用配信にも使えます。年収などの制限はライセンス本文を確認してください。生成はあなたのPC上だけで完結します。

API・OBS・Stream Deck対応

ローカル HTTP API で Generate / Stream / Play / Stop を操作できます。OBS や Stream Deck、チャット連携からも同じエンドポイントを叩けます。 API ドキュメント

任意の音楽をアップロード

好きな音声をアップロードして再生できます。配信のイントロやジングルを流してから、生成BGMへクロスフェードで切り替えることも可能です。

出力フォーマットを選択

OPUS、AAC、MP3、WAV から選べます。配信用の軽量コーデックから、編集用の非圧縮まで用途に合わせて書き出せます。

プリセット

気に入った設定をプリセットとして保存。枠の流れに合わせて切り替えられます。

作った曲は何度でも再生

一度つくった曲は残ります。配信のたびに作り直す必要はありません。何回再生しても、生成回数は増えません。

向いている使い方

配信用BGM

VTuberの雑談枠、ゲーム配信、作業配信。プリセットを切り替えて、枠の雰囲気に合う曲を切れ目なくストリーミング。

作業・勉強用BGM

lo-fi やアンビエントなど、集中しやすい雰囲気をプロンプトで指定。自分のPCだけで流し続けられます。

レストラン・店舗用BGM

店の空気に合うジャンルを指定して、オリジナルの店内BGMをローカル生成。権利まわりを気にしやすい場面でも扱いやすい構成です。

作曲の参考・スケッチ

アイデア出しやムードボード代わりに。プロンプトで方向性を試し、気に入ったテイクを書き出して作曲の出発点にできます。

使い方

  1. ログインせずに生成 — このPCで最大 5 曲。
  2. 残り曲数 / アカウント → Google で続ける、またはメール＋パスワード。無料アカウントは 100 曲（サーバー保存なので再インストールしてもリセットされません）。
  3. アップグレード で Pro を購入（ローンチセール ¥980）。Stripe 決済後、アプリに戻ると生成が無制限になります。

ログインは Google またはメール。Google のポップアップがブロックされたらメールでどうぞ。

スタジオは通常 http://127.0.0.1:8787。トップバーに残り曲数とアカウントが出ます。
