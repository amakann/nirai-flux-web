配信者のためのローカルAI音楽スタジオ

自分のパソコンで、
好きな音楽をずっと流せる。

配信者向け。好きなジャンル・プロンプトの曲を、自分のPCから切れ目なくストリーミング。 Stable Audio 3 がローカルで生成するので、クラウドの音楽APIには何も送りません。

プリセットを選んで再生。ジャンルも雰囲気も、自分の枠のまま。

できること

ローカル生成のまま、配信・作業・店舗まで幅広く使えます。

商用配信可

Stability AI Community License の条件内で、商用配信にも使えます。年収などの制限はライセンス本文を確認してください。生成はあなたのPC上だけで完結します。

API・OBS・Stream Deck対応

ローカル HTTP API で Generate / Stream / Play / Stop を操作できます。OBS や Stream Deck、チャット連携からも同じエンドポイントを叩けます。 API Doc

任意の音楽をアップロード

好きな音声をアップロードして再生できます。配信のイントロやジングルを流してから、生成BGMへクロスフェードで切り替えることも可能です。

向いている使い方

クラウドの音楽APIに頼らず、自分の世界観のまま音を流し続けたい場面向けです。

配信用BGM

VTuberの雑談枠、ゲーム配信、作業配信。プリセットを切り替えて、枠の雰囲気に合う曲を切れ目なくストリーミング。

作業・勉強用BGM

lo-fi やアンビエントなど、集中しやすい雰囲気をプロンプトで指定。自分のPCだけで流し続けられます。

レストラン・店舗用BGM

店の空気に合うジャンルを指定して、オリジナルの店内BGMをローカル生成。権利まわりを気にしやすい場面でも扱いやすい構成です。

作曲の参考・スケッチ

アイデア出しやムードボード代わりに。プロンプトで方向性を試し、気に入ったテイクを書き出して作曲の出発点にできます。
